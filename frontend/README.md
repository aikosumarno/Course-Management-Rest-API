# Data Insights Visualization 

## 1.⁠ ⁠Room Type Distribution 
A bar chart showing the number of rooms of each type across different buildings.
**Use Case/Motivation:**
It’s use case is to determine where specific types of rooms are located and how they are distributed across campus. This supports faculty members in course scheduling by allowing them to assign classes to buildings that matches their needs like labs for cpsc courses and lecture halls for large classes. Additionally, it can also highlight imbalances in room types to guide future infrastructure planning.
**Why would a decision-maker at UBC care about this visualization?**
Facilities planners and academic administrators can use this visualization to assess whether the current distribution of room types aligns with academic needs. For example, if there is a shortage of lecture halls but an excess of specialized labs, this insight can inform decisions about renovations, repurposing spaces, or future infrastructure investments.

## 2.⁠ ⁠Room Size Distribution by Building
A stacked bar chart showing the number of small (≤40 seats), medium (41–100 seats), and large (100+ seats) rooms in each building.
**Use Case/Motivation:**
It can be used to evaluate whether buildings provide an appropriate mix of room sizes to accommodate varying class sizes.
**Why would a decision-maker at UBC care about this visualization?**
Course schedulers and facilities planners can use this insight to identify mismatches between room capacity and course enrollment needs. For instance, a building with mostly small rooms may not support large classes efficiently, while buildings with many large rooms may be underutilized. This helps improve classroom allocation, scheduling efficiency, and overall space utilization.


## 3.⁠ ⁠Enrollment Trends Over Time
A line graph have years on the x axis and total number of student enrolled on the y axis, each line will represent each course.

**Use Case/Motivation:**
It can be used to estimate how many sections and total number of registration each course should open for the next semester, and also find out if specific fields are experiencing significantly growth/decline.

**Why would a decision-maker at UBC care about this visualization?**
Since the number of sections and total number of registration opened can affect the number of instructors and TAs we need. Besides, the prediction is useful to plan out course locations since different classrooms has different capacities. Finding out if specific fields are experiencing significantly growth, it helps department and course planners to see if more advanced courses can be offered for that field. And it there were a significant decline, it reminds course planners to adjust courese material, teaching method, lower the level of the course, or create market strategies if needed.
